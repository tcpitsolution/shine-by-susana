# Shine by Susana — premium demo

React + Vite + Tailwind + React Router + Framer Motion + Lucide React.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The demo uses image URLs from Unsplash for presentation imagery. Replace them with licensed/owner-approved assets before production launch.

Social links are intentionally placeholders because verified profile URLs were not supplied. Detailed service names/prices are marked as demo content. The only review displayed as real is Gabriela Garcia's 5-star Google review, per the provided business information.
